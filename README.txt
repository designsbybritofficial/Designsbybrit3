DESIGNSBYBRIT V3

DEPLOY TO VERCEL
1. Unzip this folder.
2. Make sure index.html, style.css, script.js, assets, robots.txt, sitemap.xml, and vercel.json are at the top level.
3. Upload the folder to your existing Vercel project or replace the files in your connected GitHub repository.
4. Redeploy the production branch.

BOOKING FORM
The booking form opens the visitor's email app with all project details addressed to designsbybritofficial@gmail.com.
Reference files must be attached manually in the email app.
